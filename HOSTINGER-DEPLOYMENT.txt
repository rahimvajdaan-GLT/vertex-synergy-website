VERTEX SYNERGY - HOSTINGER HOSTING NOTES

This application is a Vite/React frontend with a PHP backend.
Production is deployed by Hostinger from the protected production branch.

IMPORTANT SECURITY REQUIREMENTS:
- Never commit or publish admin passwords, hashes, API credentials, or runtime JSON data.
- Administrator configuration is maintained by the site owner on Hostinger only.
- The production PHP API currently uses api/settings.php; preserve that file until a
  separate tested migration moves the secret outside the public webroot.
- Rotate any credentials ever disclosed in prior commits or setup documentation.
- Hostinger backups and api/data/ must remain private and preserved during releases.
- To release: use Actions > Prepare manual Hostinger release PR; review draft PR,
  make a Hostinger backup, and manually merge to production if approved.
- Never push directly to production.

For the detailed procedure and outstanding security work, see SECURE-RELEASE.md.
